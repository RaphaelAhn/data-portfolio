# 에이블리 데이터 분석가 지원용 포트폴리오

> 이 문서는 에이블리 데이터 분석가 포지션을 위해, 이 저장소의 공개 데이터 기반 사례 중 고객 행동·실험 설계·의사결정 역량을 가장 직접적으로 보여 주는 두 사례를 연결한 안내문입니다.
>
> 모든 관측 수치는 공개 데이터의 오프라인 분석 결과입니다. 실제 기업의 고객·매출·캠페인 성과, A/B 테스트 결과 또는 운영 경험을 주장하지 않습니다.

## 채용 공고와의 연결

| 기대 역량 | 포트폴리오 근거 |
| --- | --- |
| 분석 결과를 실행 과제로 구체화 | 재구매 점수를 CRM 검토 큐로 제한하고, 적용 전 홀드아웃 실험·가드레일을 설계 |
| A/B 테스트와 지표 설계 | 오프라인 예측 성능과 캠페인 증분 효과를 분리하고 증분 재구매율·공헌이익·수신거부율을 향후 지표로 명시 |
| 복잡한 데이터 가공 | 취소·식별 불가·비정상 거래를 제외한 거래 정제, 세션 ID 기반 클릭스트림 집계 |
| 명확한 의사소통 | 각 결과를 관측·의사결정·한계로 나누고, 추가 증거와 다음 실험을 명시 |

## Case 1 — 고객 재구매 예측과 CRM 우선순위 설계

**사업 질문:** CRM 검토 자원이 제한돼 있을 때 어떤 고객을 먼저 검토할 것인가?

**공개 원천:** [UCI Online Retail](https://doi.org/10.24432/C5BW33). 2010-12-01부터 2011-12-09까지 영국 기반 온라인 소매업체의 공개 거래 데이터입니다.

### 분석 설계

- 취소 송장, Customer ID가 없는 행, 수량·단가가 0 이하인 행을 제외한 397,884개 거래 행을 분석했습니다.
- 고객별 최근성, 최근 90일 주문 수·구매 수량·매출·평균 주문금액·상품 다양성, 이전 180일 구매 이력을 피처로 사용했습니다.
- 무작위 분할 대신 2011-06-08, 07-08, 08-08의 과거 스냅샷으로 학습하고 2011-09-08 기준의 미래 90일 재구매를 최종 평가했습니다.
- 상위 10% 고객을 검토하는 포트폴리오 가정 아래, 최근성 기준선과 L2 정규화 로지스틱 회귀를 비교했습니다.

### 관측 결과

최종 평가 대상 3,357명 중 57.0%가 이후 90일 내 재구매했습니다.

| 방법 | ROC-AUC | 검토 고객 수 | Precision@Top 10% | Recall@Top 10% | 포착한 재구매 고객 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 최근성 기준선 | 0.687 | 336 | 78.9% | 13.8% | 265 |
| 로지스틱 회귀 | **0.735** | 336 | **95.5%** | **16.8%** | **321** |

동일한 336명 검토 용량에서 모델은 최근성 기준선보다 재구매 고객 **56명**을 더 포착했습니다. 이는 오프라인 우선순위 성능의 근거이며, 메시지나 혜택이 재구매를 유발했다는 증거는 아닙니다.

### 실행과 검증의 경계

실제 적용 시 점수는 자동 발송이 아닌 사람 검토 큐의 입력으로만 사용합니다. 고점수 고객은 최근 구매 카테고리·주문금액·구매 주기를 검토해 개인화 후보를 선정하고, 실제 효과는 무작위 홀드아웃으로 다음 지표를 확인해야 합니다.

- 증분 재구매율
- 공헌이익
- 수신거부율 및 접촉 빈도

마진, 재고, 수신 동의, 마케팅 노출 데이터가 없으므로 이 공개 데이터만으로 실제 캠페인 정책을 결정할 수는 없습니다.

## Case 2 — 공개 클릭스트림 기반 세션 탐색 행동 분석

**사업 질문:** 사용자는 상품을 얼마나 깊게 탐색하며, 짧거나 긴 탐색 세션은 어떤 비중인가?

**공개 원천:** [UCI Clickstream Data for Online Shopping](https://archive.ics.uci.edu/dataset/553/clickstream%2Bdata%2Bfor%2Bonline%2Bshopping), CC BY 4.0. 2008년 4~8월 의류 쇼핑몰의 공개 클릭스트림입니다.

### 분석 설계와 관측 결과

- 165,474개 클릭을 24,026개 세션으로 집계했습니다.
- 세션별 클릭 수와 최대 클릭 순서를 탐색 깊이로 정의했습니다.
- 탐색 깊이를 1회, 2~3회, 4~6회, 7회 이상으로 구분하고 첫 클릭의 주 카테고리별 평균 클릭 수를 비교했습니다.

| 탐색 깊이 | 세션 수 | 세션 비중 |
| --- | ---: | ---: |
| 1회 | 5,042 | 21.0% |
| 2~3회 | 5,940 | 24.7% |
| 4~6회 | 5,032 | 20.9% |
| 7회 이상 | 8,012 | 33.3% |

세션당 평균 클릭 수는 **6.89회**였습니다. 첫 카테고리별 평균 클릭 수는 Trousers 7.91회, Sale 7.21회, Blouses 5.99회, Skirts 5.85회였습니다.

### 제품 의사결정으로의 연결

짧은 탐색은 빠르게 원하는 상품을 찾은 만족 세션일 수도 있어, 클릭 수만으로 제품 문제라고 판단하지 않습니다. 실제 서비스에서는 구매·장바구니·검색어·로딩 오류·유입 채널·재고·정렬·필터 사용을 함께 수집한 뒤 아래 가설을 실험으로 검증합니다.

| 관측 | 검증할 가설 | 성공 판단 |
| --- | --- | --- |
| 1회 탐색 세션 21.0% | 특정 진입면에서 상품 적합성 또는 탐색 흐름이 약한가? | 구매/장바구니 전환, 검색 재시도, 오류율 |
| 카테고리별 탐색 깊이 차이 | 정렬 또는 필터가 탐색 부담을 낮추는가? | 탐색 후 전환, 필터 사용률, 재방문 |
| 7회 이상 세션 33.3% | 긴 탐색은 높은 관심인가, 탐색 마찰인가? | 전환, 체류, 반복 클릭, 오류율 |

이 데이터에는 구매·매출·실험군·장기 사용자 식별자가 없으므로 전환율·매출·리텐션·인과 효과는 주장하지 않습니다.

## 재현성과 데이터 사용 원칙

- 원천 데이터 행은 이 저장소에 포함하지 않습니다.
- 각 프로젝트는 원천 링크, 전처리 규칙, 분석 코드 또는 결과 산출물을 제공합니다.
- 분석 예측력, 실제 캠페인의 증분 효과, 운영 성과는 서로 다른 증거 수준으로 구분합니다.
- 공개 데이터의 2008년·2010~2011년 시장 특성을 현재 특정 기업이나 고객군에 일반화하지 않습니다.
