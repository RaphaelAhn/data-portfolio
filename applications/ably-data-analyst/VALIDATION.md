# 검증 기록 — 에이블리 데이터 분석가 지원용 안내문

## 수용 기준

1. 안내문의 수치가 각 프로젝트의 체크인된 분석 결과와 일치한다.
2. 공개 원천, 데이터 범위 및 재현 경로를 명시한다.
3. 실제 기업 성과·캠페인 증분 효과·A/B 테스트 결과로 오해할 표현을 사용하지 않는다.
4. 원천 데이터의 행 또는 개인정보를 저장소에 추가하지 않는다.
