# 이상거래 리스크 스코어링

공개 시뮬레이션 거래 데이터를 이용해, 제한된 검토 인력이 먼저 확인할 거래의 우선순위를 정하는 오프라인 모델링 프로토타입입니다.

> **범위 고지**: 실제 금융 서비스의 고객 데이터나 운영 결과가 아닙니다. 이 사례의 수치는 공개 시뮬레이션 데이터에서의 오프라인 평가 결과이며, 손실 감소·고객 경험·규제 적합성·온라인 운영 성능을 의미하지 않습니다.

## Problem

모든 거래를 자동 판정하는 대신, **일일 100건의 검토 대기열**을 전제로 거래를 위험 점수 순으로 정렬했습니다. 이 때문에 전체 분류 성능만이 아니라 상위 100건의 검토 효율을 함께 평가했습니다.

## Validation design

- 시간 순서로 학습·평가 구간을 분리
- 학습과 최종 평가 사이에 **7일 레이블 지연** 구간 적용
- 최종 테스트: 거래 66,741건, 시뮬레이션 이상거래 614건
- 기준선: Logistic Regression
- 비교 모델: HistGradientBoosting (HGB)

## Results

| Metric | Logistic Regression | HistGradientBoosting |
| --- | ---: | ---: |
| PR-AUC | 0.555 | 0.732 |
| Precision@100 | — | 63.7% |
| Recall@100 | — | 72.6% |

- **Precision@100**: 검토한 상위 100건 중 이상거래의 비율
- **Recall@100**: 전체 시뮬레이션 이상거래 중 상위 100건 검토 목록에 포함된 비율

### Segment analysis

50–99 금액 구간에서는 이상거래 160건 중 94건을 포착해 재현율 58.8%를 기록했습니다. 상위 100건 검토 목록 밖에 남은 66건은, 추가 특징 설계와 임계값 점검이 필요한 우선 구간으로 해석했습니다.

## Reproducibility and data policy

이 저장소는 포트폴리오 허브로서 원천 데이터와 실행 코드를 포함하지 않습니다. 따라서 여기서의 결과를 즉시 재실행할 수는 없습니다. 코드와 재현 절차는 정리·검증 후 별도 프로젝트 저장소에 공개하고, 이 페이지에 연결할 예정입니다.

원천 데이터, 개인 정보, 비공개 설정값은 포함하지 않습니다.

## Limitations and next steps

- 실제 고객·거래 데이터의 대표성은 검증하지 않았습니다.
- 손실 감소, 고객 경험, 공정성·규제 적합성, 온라인 서빙·모니터링 성능은 측정하지 않았습니다.
- 다음 단계는 취약 구간의 특징 보강, 시간 분할 재검증, 운영 지표와 공정성 검토입니다.
