# 이상거래 리스크 스코어링


공개 시뮬레이션 거래 데이터를 이용해, 제한된 검토 인력이 먼저 확인할 거래의 우선순위를 정하는 오프라인 모델링 프로토타입입니다.


[English version](README.en.md)


> **범위 고지**: 실제 금융 서비스의 고객 데이터나 운영 결과가 아닙니다. 이 사례의 수치는 공개 시뮬레이션 데이터에서의 오프라인 평가 결과이며, 손실 감소·고객 경험·규제 적합성·온라인 운영 성능을 의미하지 않습니다.


## Problem


모든 거래를 자동 판정하는 대신, **일일 100건의 검토 대기열**을 전제로 거래를 위험 점수 순으로 정렬했습니다. 이 때문에 전체 분류 성능만이 아니라 상위 100건의 검토 효율을 함께 평가했습니다.


## Validation design


- 시간 순서로 학습·평가 구간을 분리
- 학습과 최종 평가 사이에 **7일 레이블 지연** 구간 적용
- 최종 테스트: 거래 66,741건, 시뮬레이션 이상거래 614건
- 기준선: Logistic Regression
- 비교 모델: HistGradientBoosting (HGB)


## Results


| Metric | Logistic Regression | HistGradientBoosting |
| --- | ---: | ---: |
| PR-AUC | 0.555 | 0.732 |
| Precision@100 | — | 63.7% |
