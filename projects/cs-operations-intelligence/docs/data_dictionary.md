# 데이터 사전

| 테이블 | 핵심 필드 | 용도 | 유의점 |
| --- | --- | --- | --- |
| `fact_ticket` | 생성시각, 유형, 채널, 상태, 처리시간, 재문의 | 문의량·SLA·재문의 KPI | 고객 원문/PII는 분석 마트에 저장하지 않음 |
| `fact_agent_activity` | 상담사, 배정/처리량, 근무시간 | 팀 단위 처리 여력 분석 | 개인 인사평가나 자동 배정의 단독 근거로 사용 금지 |
| `fact_ai_assist` | 정책 버전, 검색점수, 위험도, 라우팅, 검수결과 | AI 품질·비용·검수 성과 | 모델/프롬프트 버전도 운영 시 함께 기록 |
| `dim_policy_version` | 정책 ID, 버전, 유효기간 | 답변 근거 최신성 | 유효기간 밖 정책은 검색에서 제외 |

## 데이터 품질 계약

- 티켓 ID는 고유해야 하며 생성 시각, 상태, 유형, 처리시간은 비어 있을 수 없음.
- 처리시간은 0 이상이어야 함.
- 원문 문의는 LLM 호출 전 PII를 마스킹하고, 마스킹 전 원문을 감사 로그·출력 파일에 남기지 않음.
