# AI 라우팅 및 사람 검수 정책

| 조건 | 라우팅 | 이유 |
| --- | --- | --- |
| 정책 검색 점수가 낮음 | 전문 상담사 검수 | 정책 근거 없는 답변 방지 |
| 재문의, 미처리, SLA 위험 | 전문 상담사 검수 | 고객 영향이 커질 가능성 |
| 보상·개인정보·비밀번호·인증번호 등 고위험 키워드 | 전문 상담사 검수 | 금전·보안 관련 자동 처리 금지 |
| 위 조건이 없고 정책 근거가 충분함 | 상담사 승인 | AI는 초안을 제시하고 상담사가 최종 결정 |

이 규칙은 가상 데이터 포트폴리오용입니다. 실제 운영의 임계값은 과거 티켓, 정책, 고객 영향, 법무·보안 검토를 바탕으로 검증해야 합니다.
