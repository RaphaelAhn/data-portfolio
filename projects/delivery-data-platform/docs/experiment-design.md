# 배차 정책 A/B 테스트 데이터 설계

## 분석 단위

실험 분석의 기본 단위는 주문입니다. 각 주문에 대해 실험 배정, 노출, 배차 시도, 최종 배차 결과, 취소·완료 결과를 시간 순서대로 보존합니다.

| 데이터 | 최소 필드 | 목적 |
| --- | --- | --- |
| 배정 | `order_id`, `experiment_id`, `variant`, `assigned_at` | 실험군/대조군의 고정 배정 |
| 노출 | `order_id`, `experiment_id`, `exposed_at`, `policy_version` | 실제 정책 적용 여부 확인 |
| 결과 | `order_id`, `dispatch_id`, `result`, `completed_at` | 배차·배달 품질 지표 계산 |
| 맥락 | `region_id`, 주문 시각, 주문 유형 | 층화 분석 및 데이터 품질 점검 |

## 분석 전 안전장치

1. 실험 기간 밖의 이벤트를 제외합니다.
2. 배정은 되었으나 노출되지 않은 주문을 의도치 않게 처리군 성과에 포함하지 않습니다.
3. 실험군 비율이 계획과 현저히 다른 경우 SRM 가능성을 조사합니다.
4. 지역·시간대별 주문 구성 차이를 확인합니다.
5. 고객 속도뿐 아니라 라이더 안전·가동률·취소와 같은 가드레일 지표를 함께 봅니다.

## 해석 경계

이 설계는 분석 가능한 데이터셋을 만드는 원칙을 보여 줍니다. 인과 효과의 결론은 사전에 합의한 실험 설계, 샘플 크기, 종료 규칙, 운영 정책 변경 여부를 검토한 뒤에만 내려야 합니다.
